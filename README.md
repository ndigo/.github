# Ndigo organization

This repository holds organization-wide GitHub configuration for [Ndigo](https://github.com/ndigo).

The public organization profile is rendered from [`profile/README.md`](profile/README.md) at [github.com/ndigo](https://github.com/ndigo).

## Community health files

The following files at the repository root are inherited by every repository
in the organization that does not define its own:

- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — Contributor Covenant 2.1
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — baseline contribution guidelines
- [`SECURITY.md`](SECURITY.md) — vulnerability reporting policy
- [`CONVENTIONS.md`](CONVENTIONS.md) — baseline code conventions

Sponsorship configuration (`FUNDING.yml`) is tracked separately; see
[ndigo/ndigo#635](https://github.com/ndigo/ndigo/issues/635).
